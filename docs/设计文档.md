## 1. 设计理念

### 1.1 视觉叙事：“深邃夜空与岛屿灯火”

“星”是个人亮点与职业展示，“屿”是由个人掌控的独立数字空间。视觉系统围绕这对意象展开：

- **夜空是底色。** 默认暗色主题，深蓝黑（ink）承载内容，传递深度、专注与秩序。公开门户在夜空下像一座灯塔：清晰、快速、可信。
- **灯火是点缀。** 暖金（glow）只用于强调、进行中状态与人情味细节，不大面积铺陈；星蓝（star）承担主交互色，是夜空中可点击的“航标”。
- **公开轻，私有稳。** 公开面留白多、节奏慢、装饰克制，服务于求职展示的可信感；控制台密度更高、工具感更强，状态反馈优先于视觉修饰。

### 1.2 设计原则

1. **暗色优先，亮色可达。** 暗色是品牌默认；亮色主题完整定义、同等可用，不是事后补丁。
2. **内容先于装饰。** 星空粒子、复杂动效属于 Should/Could 增强项，永不挤占对比度、焦点、加载性能与内容准确性。
3. **任何背景下文字可读。** 自定义背景与主题正交：背景在最底层，内容层永远有可调 scrim 遮罩。
4. **状态诚实。** 加载、空、错误、降级都有明确设计；不伪造实时数据、不假装异步操作已完成、不伪造引用来源。
5. **单用户温度。** 文案克制、第一人称、无运营腔；错误提示说明发生了什么、可以怎么做。

## 2. 设计令牌

### 2.1 品牌基色

与前端开发计划 §5.1 完全一致，不改名、不改值：

```css
/* apps/web/src/styles/global.css 的规划令牌；源码就位后实现并验证 */
@theme {
  --color-ink: #0b1020;
  --color-ink-soft: #141b33;
  --color-star: #7aa2ff;
  --color-glow: #ffd479;
  --color-paper: #f7f7fb;
  --font-display: "Noto Serif SC", serif;
  --font-body: "Inter", "Noto Sans SC", sans-serif;
  --radius-card: 1rem;
}
```

### 2.2 语义色（双主题）

语义令牌在暗色主题下定义为下表“暗色”列；亮色主题在 `:root[data-theme="light"]` 下重定义。**亮色列是规划初值，实现时必须用对比度工具逐一验证**：正文与背景 ≥ 4.5:1，大字号文本（≥ 1.25 rem 粗体或 ≥ 1.6 rem）≥ 3:1，图标与控件边界 ≥ 3:1。任一初值不达标时调整明度而非色相，并把最终值回写本文。

| 语义令牌 | 暗色 | 亮色（初值） | 用途 |
| --- | --- | --- | --- |
| `--color-bg` | `ink #0b1020` | `paper #f7f7fb` | 页面底色 |
| `--color-surface` | `ink-soft #141b33` | `#ffffff` | 卡片、面板 |
| `--color-text` | `#e8ecf8` | `#161c30` | 正文与标题 |
| `--color-text-dim` | `#9aa5c4` | `#4c567a` | 次要文本、元信息 |
| `--color-border` | `#26304f` | `#dde2f0` | 分隔线、卡片描边 |
| `--color-accent` | `star #7aa2ff` | `#3a5ccc` | 链接、主按钮、焦点环 |
| `--color-accent-warm` | `glow #ffd479` | `#9a6200` | 强调、进行中、精选标记 |
| `--color-success` | `#7ddba3` | `#1a7f4b` | 成功状态 |
| `--color-warning` | `#ffd479` | `#92600a` | 警告状态 |
| `--color-danger` | `#ff9a9a` | `#c43d3d` | 错误、破坏性操作 |
| `--color-scrim` | `ink` 35%–55% 渐变 | `paper` 40%–60% 渐变 | 背景图之上的可读性遮罩 |

规则：状态色不作为信息的唯一载体（同时配图标或文字）；`accent-warm` 不与 `warning` 在同一语义场景混用；破坏性按钮使用 `danger`，不用暖金。

### 2.3 字体与字阶

- 展示字体 Noto Serif SC：仅用于 Hero、页面标题、引用与品牌字标；正文一律 Inter + Noto Sans SC。
- 等宽字体使用系统栈 `ui-monospace, "Cascadia Mono", Consolas, monospace`，**不引入第三款网络字体**，把字体预算留给中文子集。
- 中文字体按公开内容子集化并 `font-display: swap`（预算见前端开发计划 §5.2）。

字阶按 1.25 比率，基线 1 rem = 16 px：

| 令牌 | 尺寸 | 行高 | 用途 |
| --- | --- | --- | --- |
| `text-xs` | 0.8 rem | 1.5 | 元信息、徽章、表格辅助列 |
| `text-sm` | 0.9 rem | 1.5 | 次要正文、卡片描述 |
| `text-base` | 1 rem | 1.75 | 正文（中文长文舒适行高） |
| `text-lg` | 1.25 rem | 1.5 | 小节标题、卡片标题 |
| `text-xl` | 1.6 rem | 1.3 | 页面副标题 |
| `text-2xl` | 2 rem | 1.25 | 页面标题（展示字体） |
| `text-display` | `clamp(2rem, 1.2rem + 4vw, 3.05rem)` | 1.2 | Hero（展示字体，流式缩放） |

字重：展示字体 600；正文 400；强调与按钮 500–600；不使用 300 以下的细字重（小字号下对比度不可控）。

### 2.4 间距、圆角与阴影

间距使用 4 px 基网格：

| 令牌 | 值 | 典型用途 |
| --- | --- | --- |
| `space-1` / `space-2` | 4 / 8 px | 图标间距、徽章内距 |
| `space-3` / `space-4` | 12 / 16 px | 卡片内距、表单间距 |
| `space-6` / `space-8` | 24 / 32 px | 卡片间距、区块内分隔 |
| `space-12` / `space-16` | 48 / 64 px | 区块节奏（移动端用 space-12，桌面用 space-16） |

圆角：`radius-sm 0.375rem`（徽章、输入框）、`radius-md 0.5rem`（按钮、小卡片）、`radius-card 1rem`（卡片与面板）、`radius-full`（Tag、头像、进度条）。

阴影从简，暗色主题下主要靠 `surface + border` 分层，只保留两级投影：`shadow-1`（卡片悬浮，`0 1px 2px rgb(0 0 0 / .24), 0 8px 24px rgb(3 6 18 / .32)`）与 `shadow-2`（模态、播放条上浮）。亮色主题同步降低阴影不透明度。不使用彩色发光阴影做装饰；“星芒”气质通过 accent 色 1 px 描边与暖金点缀表达。

### 2.5 层级（z-index）

| 层级 | 值 | 内容 |
| --- | --- | --- |
| 背景层 | 0 | BackgroundLayer（预设图或 IndexedDB Blob） |
| 遮罩层 | 1 | scrim |
| 内容层 | 10 | 页面内容 |
| 吸顶导航 | 40 | Navbar / 控制台顶栏 |
| 播放器迷你条 | 50 | 底部固定，含安全区内距 |
| 模态 / 抽屉 | 60 | Modal、PlaylistPanel、移动端导航抽屉 |
| Toast / 全局提示 | 70 | StatusBanner 浮动实例 |

### 2.6 断点

沿用 Tailwind 默认断点：`sm 640 / md 768 / lg 1024 / xl 1280`。容器约束来自前端开发计划 §5.1：页面最大宽度 72 rem（约 1152 px，lg–xl 之间），正文内容栏 48 rem（约 768 px，恰好 md）。控制台内容区为流式宽度，不套用 48 rem 栏。

- Navbar 左为字标“星屿 StarIsle”（Noto Serif SC，无图片 Logo），右为导航链接 + ThemeToggle（◐）+ 背景设置入口（▣）+ 播放器入口（♪）；二期追加“登录 / 控制台”入口。

### 4.2 项目页 `/projects`（一期，公开）

- 结构：页头（标题 + 快照来源与采集时间说明）→ 内容集合项目（长文介绍，48 rem 栏）→ 仓库快照区（筛选 + RepoGrid）。
- 筛选：来源（全部 / GitHub / Gitee）+ 排序（featured 优先 / 最近更新）；筛选控件为分段按钮，不做实时请求，只过滤构建期 JSON。
- 状态：抓取失败的降级快照用 StatusBanner（info）说明“数据为构建期快照，采集于 YYYY-MM-DD”；两来源均未配置时显示 EmptyState，不虚构仓库。
- RepoCard 必含：名称、描述（两行截断）、LanguageDot + 语言名、stars / forks、更新时间、来源徽章、featured 徽章。

### 4.3 简历页 `/resume`（一期，公开）

- 在线简历使用 48 rem 内容栏排版（展示字体标题 + 正文字体），顶部提供“下载 PDF”按钮（仅在 PDF 经确认放入 `public/` 后渲染）。
- 打印样式属于 M1：`@media print` 下隐藏 Navbar/Footer/背景层，输出纯黑白排版。
- SEO：`Person` 结构化数据只出现在本页与首页。

### 4.4 登录与注册 `/login`（二期，公开）

视觉与交互以上传的参考稿（[登陆注册html.txt](./登陆注册html.txt)、[登陆注册css.txt](./登陆注册css.txt)）为蓝本，适配星屿令牌体系。参考稿与本设计的对位关系：

| 参考稿 | 星屿令牌 / 规范 |
| --- | --- |
| `royalblue` 主色 | `--color-accent`（暗色 star / 亮色 #3a5ccc） |
| 白色卡片、20 px 圆角 | `--color-surface` + `--color-border`、`--radius-card` |
| 输入框 10 px 圆角 | `--radius-md` |
| valid 绿色标签 | `--color-success`（失败态用 `--color-danger`，参考稿未定义失败态） |
| 0.3 s ease 过渡 | 200 ms ease-out（§8） |
| 标题脉冲双点（1 s 无限循环） | 保留为品牌装饰，`prefers-reduced-motion` 下静止 |
| 灰色说明文字 | `--color-text-dim` |

参考稿仅借鉴交互与视觉模式，不逐行复制进源码；其来源与许可证待登记后，再决定参考文件是否长期保留在仓库中。

#### 4.4.1 认证卡片（AuthCard）通用规范

- 居中单栏卡片：最大宽度 22 rem（≈ 参考稿 350 px），`radius-card`、`surface + border`、`shadow-1`，内距 1.25 rem，表单项纵向间距 0.75 rem；并排字段行（名 / 姓）用 flex 各 50%、间距 0.75 rem。
- 标题：`text-xl`、600 字重、accent 色、字距 -0.02 em；左侧双圆点装饰（CSS `::before / ::after` 绘制，1 s 脉冲扩散，`aria-hidden` 纯装饰）。
- 副标题（message）：`text-sm`、`text-dim`，一行说清当前形态（登录 / 初始化）。
- 底部切换链接：居中 `text-sm`、accent 色、hover 下划线（对应参考稿 `.signin`）。

#### 4.4.2 下沉式浮动标签输入框（FloatInput）

参考稿的签名交互：标签初始位于输入行内，聚焦或已有值时**下沉**到输入框底部预留区并缩小加重（与常见的“上浮标签”相反，是本设计保留的特征）。

```text
初始 / 空值：                 聚焦或有值：
┌──────────────────────────┐  ┌──────────────────────────┐
│ 密码                      │  │ ••••••••                 │
│                          │  │ 密码   ← 下沉、缩小、加重   │
└──────────────────────────┘  └──────────────────────────┘
```

- 结构：`<label>` 包裹 `<input>` 与 `<span>`，天然完成标签关联；不拿 placeholder 充当标签。
- 几何：输入框内距上 10 px、两侧 10 px、下 20 px（为下沉标签预留底部空间），控件总高 ≥ 44 px；1 px `--color-border` 描边、`--radius-md`。
- 标签动画：初始 left 10 px / top 15 px / `text-sm` / `text-dim`；聚焦或有值时下移至底部预留区、缩小至约 0.7 倍、600 字重——聚焦 accent 色、校验通过 success 色、校验失败 danger 色；过渡 200 ms ease-out。
- 焦点可见性：参考稿的 `outline: 0` 不可照搬——去除默认 outline 的同时必须叠加 §10 的焦点环（2 px accent + 2 px 偏移）。
- 校验与播报：利用 `required` + `type` 驱动 `:valid / :invalid`；错误文案经 `aria-describedby` 关联并以 `role="alert"` 播报；浏览器自动填充（autofill）样式按 surface 背景重设，避免默认黄底破坏暗色主题。
- 密码框右端内嵌“显示 / 隐藏”图标按钮（≥ 44 px 触达区、带文字标签）。

#### 4.4.3 登录形态（十周 MVP，二期）

```text
┌────────────────────────────────────┐
│  ✦ 登录 StarIsle                    │ ← 脉冲双点 + accent 标题
│  进入你的岛屿控制台。                 │ ← message
│  ┌──────────────────────────────┐  │
│  │ 密码（FloatInput + 显隐切换）  │  │
│  └──────────────────────────────┘  │
│  [             登 录             ]  │ ← 主按钮，提交中 loading
│  错误提示区（aria-live）            │
└────────────────────────────────────┘
```

- 单密码字段（单用户契约 `POST /auth/login` 仅需 `{ password }`）；静态壳 + `client:load` LoginForm。
- 状态：401 显示通用失败文案（不泄露账号细节）；429 显示冷却倒计时；CSRF 获取失败显示可重试错误。登录成功跳回 `redirect`（仅站内相对路径）。
- MVP 登录页不渲染“注册 / 找回密码”入口——单用户系统当前无此流程；底部切换链接仅在 §4.4.4 的预留形态获批准后使用。

```text

│  ✦ 创建账户                         │
│  初始化你的岛屿，仅首次可进入。        │
│  ┌─────────────┐ ┌─────────────┐  │ ← 名 / 姓并排（预留字段）
```

## 5. 组件设计规范

按前端开发计划 §9 的组件族组织；每族列出变体、必须覆盖的状态与交互要点。组件示例页负责在不引入 Storybook 的前提下展示这些状态。

### 5.1 通用 UI

| 组件 | 变体 / 规格 | 必覆盖状态 | 要点 |
| --- | --- | --- | --- |
| Button | primary（accent 实底，暗色主题配 ink 文字、亮色主题配白字，文字对比 ≥ 4.5:1）、secondary（描边）、ghost（无框）、danger；高 32 / 40 / 48 px 三档，触屏场景最小 44 px | default、hover、active、focus-visible、disabled、loading（spinner 替换文案，宽度不塌） | 焦点环 2 px accent + 2 px 偏移，双主题下均 ≥ 3:1 |
| Card | `radius-card`、surface + border、悬浮 `shadow-1` | default、hover（仅桌面）、loading 骨架 | 卡片整体可点时用单 `<a>` 包裹，不用堆叠链接 |
| Modal | 最大 32 rem，scrim 背景 | 打开 / 关闭过渡、 destructive 确认变体 | 焦点圈禁、ESC 关闭、关闭后焦点还原 |
| Tag | `radius-full`、accent 描边或暖金点 | default、可移除（kbd 可删） | 不止颜色区分含义 |
| EmptyState | 图标 + 标题 + 描述 + 可选主操作 | — | 文案给下一步（见 §12） |
| StatusBanner | info / success / warning / error，图标 + 文本 + 可选操作 | 静态与可关闭两种 | 动态出现走 `aria-live="polite"` |

### 5.2 站点组件

- Navbar：小屏抽屉、当前页 `aria-current`、减少动效下无过渡。公开 / 私有入口按 session 状态渲染，未登录不显示控制台链接。
- ThemeToggle：太阳 / 月亮图标切换，有文字标签（读屏）；切换无闪烁（见 §7）。
- ModuleDock：模块入口卡组；私有模块未登录时点击跳 `/login?redirect=...`。
- Footer：快照时间、来源与许可证说明、备案/版权占位（待实际信息确认）。

### 5.3 仓库组件

- RepoCard / RepoGrid：状态含正常、快照降级（网格上方 Banner）、单来源缺失、全部缺失空态；featured 排序由本地清单决定，UI 不出现“pinned”字样。
- LanguageDot：色点 + 文字语言名（颜色不单独表义）。

### 5.4 背景组件

见 §6。BackgroundPicker 必覆盖：无 IndexedDB 权限、压缩失败、超限（原图 > 15 MB）拒绝、恢复默认、预设选择。

### 5.5 播放器组件

```text
┌──────────────────────────────────────────────────────┐
│ [封面] 曲名 — 艺人   ⏮ ▶ ⏭   ──●──── 01:23/03:45  🔊 ≡ │ ← 底部迷你条（z50）
└──────────────────────────────────────────────────────┘
```

- MusicPlayer：播放 / 暂停、切歌、进度续播、音量；迷你条与 PlaylistPanel 共享 nanostores 状态。
- ProgressBar：滑杆键盘可操作（←/→ 步进 5 秒），有 `aria-valuetext` 读秒。
- 状态：媒体加载失败（Toast + 可手动跳过）、自动播放被浏览器拦截（显示待点击的播放钮，不静音偷跑）、输入框聚焦时快捷键不劫持。

- AuthCard / FloatInput：认证卡片与下沉式浮动标签输入框，规范见 §4.4.1–§4.4.2，登录与初始化（预留）两种形态共用。
- LoginForm：见 §4.4.3；提交中禁用按钮并 loading；错误区 `aria-live`。
- RegisterForm（预留）：见 §4.4.4；未获总体具体开发计划决策门前不进入开发排期。

### 5.7 私有资源组件

- PhotoTimeline / DropZone / FileTable / MailList / MailReader：见 §4.6–§4.8；统一规范——上传进度单项可见、超限即时反馈、删除二次确认、失败回滚不假装成功、空态给下一步。

### 5.8 知识库组件

- JobStatus 五态配色：排队（text-dim）、运行中（accent-warm 脉冲）、成功（success）、失败（danger + 错误码）、已取消（text-dim）。
- MessageBubble：用户右对齐（accent 淡底），助手左对齐（surface）；流式期间末尾渲染闪烁光标，`done` 后移除。
- CitationCard：`[序号] 文档名 vX · chunk #n` + 片段摘要，悬停/聚焦展开完整片段；无引用回答下方显示 warning Banner（“本次回答未找到可引用的来源”）。

## 6. 背景与可读性系统

```text
z:0  BackgroundLayer —— 预设背景或 IndexedDB Blob；cover / center
z:1  Scrim —— 语义色渐变遮罩（暗色 ink 55%→35%，亮色 paper 60%→40%）
z:10 Content —— 所有文本与控件
```

- 背景与主题**正交**：换主题不动背景，换背景不动主题；scrim 随主题切换，保证任一组合下正文对比 ≥ 4.5:1。
- BackgroundPicker 提供：预设背景网格（自有/授权素材）、本地上传、scrim 透明度滑杆、背景模糊滑杆、恢复默认。
- 失败与降级：原图 > 15 MB 拒绝并提示重选；压缩 / 编码失败提示重选或降质，不回退保存超大原图；IndexedDB 不可用时回退预设背景并明确说明无法本地持久化。
- 性能：防闪烁脚本只恢复主题偏好；背景 Blob 在首屏后异步读取并淡入（≤ 250 ms），不做同步 IndexedDB 读取阻塞渲染；最终 Blob 目标 < 1.5 MB（预算见前端开发计划 §5.2）。

## 7. 主题系统与防闪烁

- 主题以 `data-theme="dark|light"` 应用在 `<html>`；默认暗色（品牌方向），ThemeToggle 切换并写入 localStorage 偏好。
- 防闪烁：`<head>` 内联脚本只恢复主题偏好（不碰背景），避免 FOUC；脚本体积保持极小，不计交互逻辑。
- 所有组件只消费语义令牌（§2.2），不写死品牌色，保证亮色主题一键成立。
- “跟随系统”作为 Should 增强，未实现前默认暗色，不读取 `prefers-color-scheme` 做半截支持。

## 8. 动效规范

| 场景 | 时长 / 缓动 | 模式 |
| --- | --- | --- |
| 按钮 / 链接 / 卡片悬浮 | 150 ms ease-out | 颜色、描边、位移 2 px |
| 页面区块入场 | 200 ms ease-out | 透明度 + 上移 8 px，首屏区块不用 |
| Modal / 抽屉 / PlaylistPanel | 200 ms ease-out | 缩放 0.98→1 / 滑入 + 淡入 |
| Toast / StatusBanner | 200 ms ease-out | 顶部滑入 |
| 背景淡入 | 250 ms ease-out | 仅透明度 |
| 骨架屏 | 1200 ms | 微光扫过（surface 两档明度） |
| 认证卡片标题脉冲点 | 1000 ms linear 循环 | scale 0.9→1.8 + 透明度淡出；纯装饰，reduced-motion 下静止 |

- 只允许 `transform` 与 `opacity` 参与动画（合成层属性），进度条用 `scaleX` 而非 `width`。
- `prefers-reduced-motion`：全部动效降级为即时切换或纯透明度 ≤ 150 ms；脉冲点、微光、粒子全部静止。
- 星空粒子 / 视差等氛围动效属于 Should/Could，一期默认不实现；实现时也必须满足减少动效降级与首屏 JS 预算。

## 9. 响应式与触摸

- 断点行为：RepoGrid 3→2→1 列；邮件双栏→单栏互斥；控制台侧栏→底部标签栏；表格→卡片列表。
- 触摸目标 ≥ 44×44 px；相邻目标间距 ≥ 8 px；底部固定元素（播放条、标签栏）含 `env(safe-area-inset-bottom)`。
- hover 不承载唯一信息：卡片悬浮出现的操作在触屏上常显或收纳进“⋯”菜单。
- 窄屏回归是 M2/M3 验收的一部分（相册、邮件、聊天三个高密度界面在 360 px 宽逐一走查）。

## 10. 可访问性规范

- 对比度：正文 ≥ 4.5:1，大文本 ≥ 3:1，控件边界与图标 ≥ 3:1；§2.2 亮色初值逐一验证后回写。
- 焦点：全站可见焦点环（2 px accent + 2 px 偏移）；跳转主内容的 skip link 为每个布局第一焦点。
- 键盘：公开页全路径可键盘走查（M1 门禁的一部分）；播放器 ←/→ 调进度、空格播放暂停（输入框聚焦时不劫持）；Modal ESC 关闭且焦点还原。
- 语义与读屏：landmark 完整（header/nav/main/footer）；动态更新（Toast、流式阶段、未读数）用 `aria-live="polite"`；图标按钮必须有文字标签。
- 颜色不单独表义：语言点带文字、job 状态带文案、未读带“未读”前缀。
- 减少动效：见 §8。

## 11. 图标、插画与媒体

- 图标统一线性风格：1.5 px 描边、圆角端点、20 px 网格；具体图标库在实现期按包体预算评估（首屏 JS ≤ 60 KB gzip 目标内）。emoji 不作功能图标，可作内容装饰。
- 品牌标识为字标“星屿”+ 四点星芒符号（✦ 风格的 CSS/字符实现），不使用图片 Logo，省去请求与体积。
- 项目 / 仓库卡片封面用 CSS 渐变 + 星芒图案的占位方案，不依赖外链图片。
- 所有摄影、插画、音频与视频必须自有、授权或公版，并在 Footer 的来源说明页登记；无法确认授权的素材宁可不用（对齐总体计划风险登记）。

## 12. 文案与语气

原则：简体中文；主动语态；先说明发生了什么，再给出可做的下一步；不责备用户；技术性错误码转译为口语，但保留 `requestId` 供排查；不夸大（“可能”“建议”优先于“一定”）。

| 场景 | 规划文案（初稿） |
| --- | --- |
| 仓库快照未配置来源 | “暂未配置仓库来源，构建时已跳过抓取。配置 GITHUB_USERNAME / GITEE_USERNAME 后重新构建即可展示。” |
| 仓库快照降级 | “以下为构建期快照，采集于 {date}；最新数据请访问来源平台。” |
| 登录失败 401 | “无法登录，请检查密码后重试。” |
| 登录限速 429 | “尝试过于频繁，请稍候再试。” |
| 初始化密码不一致 | “两次输入的密码不一致，请重新确认。” |
| 密码强度建议 | “建议使用至少 12 位、包含大小写字母与数字的密码。” |
| 重复访问初始化页 | “初始化已完成，请直接登录。” |
| 无权访问 403 | “当前会话无权访问该内容，请重新登录。” |
| 上传超限 413 | “文件超过大小上限（{limit}），请压缩后重试。” |
| 类型不支持 415 | “暂不支持该文件类型。” |
| 相册空态 | “还没有照片。拖放或点击上传，开始你的时间轴。” |
| 收件箱空态 | “暂无邮件。新邮件到达后会在一分钟内出现在这里。” |

| RAG 无引用 | “本次回答未找到可引用的来源，内容仅供参考。” |
| RAG 流错误 | “回答中断，可重试；已生成的部分不会保存为完整回答。” |
