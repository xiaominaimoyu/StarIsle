用户已于 2026-11-01 确认每周约 20 小时的开发投入；人员配置仍沿用原计划的单人估算。实施者指用户与 AI 协作完成的同一工作容量；内容、授权、账号和人工验收由项目所有者负责，不假定另有全职成员。

| 依据与假设 | 排期处理 |

| 已有代码与 11-01 本地检查可作为起点 | 不重复建设登录、分页、任务取消、控制台统计、上传/照片、备份或粒子系统；发生代码变化后按影响范围回归 |

## 6. S3：接入真实模型并分别评测检索与回答

| 任务 ID | 工作与依赖 | 交付物 / 验收 |
| --- | --- | --- |
| S3-01 | 所有者提供授权 chat/embedding GGUF 与硬件条件；实施者接入既有双服务接口 | 记录模型来源/许可、版本/hash、量化、维度、上下文和运行 profile；模型端口不公开；先验证 CPU 路线，GPU 是否实施取决于真实条件，不先升级整套技术栈 |
| S3-02 | 用至少 20 篇授权 PDF/Markdown/TXT 验证索引与重建 | 文档/chunk/vector/model profile 可追踪；索引 ready、重建、删除、取消、模型失败均有证据；远程 embedding 失败不静默切换为 hash-v1；变更 profile 时显式重建 |
| S3-03 | 所有者准备至少 30 个有相关来源标注的问题，实施者运行现有检索评测 | corpus/问题集版本与 fingerprint、hitRateAt20/recallAt20/mrrAt20、检索 p50/p95 有结果；评测须满足现有授权和输出目录约束 |
| S3-04 | 在相同问题集上另做真实生成、引用与异常行为评测 | 核对答案是否受来源支持、引用是否可定位；另设至少 5 个无答案问题和 5 个注入/权限干扰样例；保留失败分母，不将这些无相关来源的问题强塞进现有检索 schema |
| S3-05 | 固定问题、输入规模和生成长度测量端到端性能，再恢复复验 | 同时记录首 token 时间、完整 SSE 用时、检索用时、失败/取消和资源 profile；达到原 CPU <60 秒、GPU <10 秒量级的适用目标，未测 GPU 明确保留未验证状态；真实模型索引恢复后可检索 |

现有 [rag_eval.py](../scripts/rag_eval.py) 仅评估检索：每题必须有 relevantDocumentIds 或 relevantChunkIds，报告 `acceptanceStatus=evaluated`。它没有生成答案判分或自动质量通过门槛。检索、真实生成、无答案/注入行为和人工审阅必须分别记录；本轮不预设已经存在完整生成评测 harness。

以下为进入正式 M3 评测前拟冻结的质量建议，不是当前代码中的门禁，也不覆盖原验收要求：

| 维度 | 建议目标 | 判断方式 |
| --- | --- | --- |
| 可回答问题检索 | 30 题 hitRateAt20 ≥0.90、recallAt20 ≥0.80；MRR@20 同时报告 | 使用现有脚本，并明确文档级/chunk 级标注口径；由所有者在正式评测前确认建议值 |
| 真实答案与引用 | 30 题中至少 27 题经人工审核为主要结论有来源支持；展示的引用均能定位 | 全量保存通过/失败计数与理由；有引用但答案不受支持仍判失败，hash/模板 smoke 不计入 |
| 无答案行为 | 至少 5 个样例均不编造已查到的文档证据 | 独立行为集与人工审阅；诚实表达证据不足，不能靠添加虚构引用满足形式 |
| 注入/权限行为 | 至少 5 个样例不改变既有权限和工具边界 | 独立行为集；失败先修复并重验，不降低鉴权或引用门槛 |

这些建议值尚未成为已批准的质量基线；S0-05/S3 正式评测前确定。若模型、硬件或目标调整，先记录原因、取舍和新范围，再重跑对应评测，不通过删除失败题提高分数。

## 7. S4：发布、交接与后续体验增强

发布批次需与同一源码版本、构建输入、模型/语料 profile 和验收记录对应。交付至少包含：M1/M2/M3 结果与未测项、运行说明、恢复与回滚记录、密钥轮换引用说明、维护任务/日志轮转检查、失败处置与下次复验入口。

Git 工作须保持当前改动所有权：本地源码仍在 `c07e8f1`，前序文档改动尚未提交；后续先确认逐路径清单，读取忽略规则并扫描敏感内容，再按用户明确批准范围提交/推送。`.workbuddy/` 与历史截图的跟踪处理独立列项，不在功能提交中顺手删除或改写历史。

完整交互音效、BGM/用户音乐优先级适配、额外视觉打磨和更广设备支持作为后续体验批次安排。既有键盘/普通导航/reduced-motion/forced-colors 以及已承诺的设备验收不能因增强延期而被省略；没有设备证据的项目继续标记未验收。现有纸屑只说明粒子已实现，不代表音效或 Phase 8 完成。
